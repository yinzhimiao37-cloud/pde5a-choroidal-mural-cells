# 壁细胞稿代码与汇总结果

本仓库对应 Graefe’s Archive 壁细胞稿，与三药 FAERS 仓库分开保存。
主入口是 README.md；原始输入来源和文件路径见 INPUTS.md，运行顺序见 RUNNING.md。

## 可以直接查看的内容

- GSE183320：供体与细胞类型 PDE5A 阳性率、最低细胞数、健康标签限制、留一供体和深度匹配结果。
- GSE135922：供体和区域信息、非 PDE5A 标志物定义、共享供体排除和区域配对汇总。
- GSE318037：切片和供体级空间结果、条件置换摘要、距离曲线源表和原始下载清单。
- 壁细胞状态：亚聚类支持度、状态面板、供体级趋势、留一供体和全量标志物结果。
- LIANA：全部供体评分、匹配前后配对差值、全量检验、有效供体数和最终评分审计。
- figures 目录中的四张主图 PDF，以及聚合的 FAERS 来源敏感性场景表。

## 复现边界

仓库不含原始表达矩阵、AnnData 缓存、逐细胞坐标、FAERS 个案标识符或数据库。
先从 GEO/FDA 获取输入，再按英文说明运行；不能只下载仓库就从头完成全部分析。
查看现有汇总表不需要原始矩阵。重新运行会覆盖部分模块输出，建议另建副本。
本次只整理归档，不代表在全新环境重跑通过；所有原始统计数值保留，没有制造新阳性结果。

图形脚本对个人排版辅助工具的依赖改为可选：若未安装，会明确提示跳过排版审计。
其余原始统计脚本保留。新增的两个辅助脚本仅负责下载校验和原始 PDE5A 表达提取。
每个归档文件的校验值及原始文件校验值见 MANIFEST.csv。

三药稿共享的 FAERS 来源不是独立重复；壁细胞稿的完整个案联结账本及全部提取代码
不在此分子代码包中。数据和代码声明应保留这一共享范围说明。
